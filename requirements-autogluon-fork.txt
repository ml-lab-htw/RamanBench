# AutoGluon fork required for RamanBench reproducibility
#
# Raman spectra typically have 500–4000 wavenumber features. The official
# AutoGluon release caps tabular foundation models (TabPFN v2, TabICL, TabDPT,
# MITRA, …) at 500 features and silently skips them on larger datasets.
# This fork removes that cap so all foundation models run on the full spectral
# resolution used in the benchmark.
#
# Install this BEFORE installing raman-bench:
#
#   pip install -r requirements-autogluon-fork.txt
#   pip install raman-bench[deep]
#
# Fork: https://github.com/mario-koddenbrock/autogluon
