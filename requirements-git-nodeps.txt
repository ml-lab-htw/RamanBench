# the main environment's. Install them on top, without their dependency tree:

# A line with a Python marker is skipped on other interpreters.

# Lattice and Lattice-tiny (Prep_LATTICE, Prep_LATTICE_TINY). `lattice[fast]` pins torch==2.7.1, which
# conflicts with synthefy-nori (torch>=2.8,<2.14) in requirements-git.txt, so the two cannot be
# resolved into one environment (checked 2026-11-20 with `uv pip compile`, Linux, Python 3.11). Install
# Lattice on top of the main image without its dependency tree:
#
#     pip install --no-deps -r requirements-git-nodeps.txt
#
# TabArena's own run used torch 2.7.1 with triton 3.3.1 (the stack of Lattice's Triton fast path). Whether
# the newer torch of the main image is enough is not verified: run one real fit before queueing the sweep,
# and fall back to an image with torch 2.7.1 if it fails.
#
# The commit is the one tabarena's wrapper was written against (tabarena.models.lattice.info, `_PIP_EXTRA`).
# The weights are CC-BY-NC-4.0 (non-commercial). Bump the commit deliberately.
lattice @ git+https://github.com/hachure-ai/Lattice.git@e106f9fba5994f85aca9593ae82af561054ab77a
