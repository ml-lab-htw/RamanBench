# conflicts with synthefy-nori (torch>=2.8,<2.14) in requirements-tabarena-git.txt, so the two cannot be
# resolved into one environment (checked 2026-11-20 with `uv pip compile`, Linux, Python 3.11). Install
# Lattice on top of the main image without its dependency tree:
#
#     pip install --no-deps -r requirements-lattice-git.txt
#
# TabArena's own run used torch 2.7.1 with triton 3.3.1 (the stack of Lattice's Triton fast path). Whether
# the newer torch of the main image is enough is not verified: run one real fit before queueing the sweep,
# and fall back to an image with torch 2.7.1 if it fails.
#
