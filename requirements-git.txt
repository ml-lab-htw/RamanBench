# Packages with no PyPI release (PyPI forbids direct-URL requirements, so none of this can live in
# pyproject.toml), resolved together with the package. Install after
# `pip install raman-bench[models]` (or `[benchmark]` / `[full]`):
#     pip install --pre -r requirements-git.txt
# Every line is pinned to one commit, never to a branch head, so a run traces to one commit. Bump a
# pin deliberately. Until a package is installed, its Prep_* class raises a "not available" error
# (preprocessing/wrapped_models.py). Packages that cannot be resolved with the rest are in
# requirements-git-nodeps.txt.
#
# --- tabarena ---------------------------------------------------------------------------------
# tabarena, pinned to a commit of autogluon/tabarena main (39c3b4a8, 2026-11-20).
#
# In a non-fresh env use `--force-reinstall`: pip matches on the version string, so it
# silently skips this line if any tabarena 0.1.0 is already installed. Check
# `site-packages/tabarena-*.dist-info/direct_url.json` for the real commit. Afterwards
# re-check torch and torchvision (a forced tabarena reinstall can move torch).
#
# Extras left out of the Python 3.11 image, each with its own install:
#   tabh2o, agentic_mlp, agentic_tabm  need Python >=3.12 (TabH2O, MLP-A, TabM-A).
#   tabstar_v1p1  tabstar 1.2.0 caps transformers<5 but synthefy-nori needs transformers>=5.
#                 The Dockerfile installs tabstar with --no-deps; peft and skrub are
#                 further down in this file.
#   lattice       lattice[fast] pins torch==2.7.1, which cannot be resolved with the nori extra's
#                 torch>=2.8. Install it on top with requirements-git-nodeps.txt.
#   seldon        neuralk-oss needs a structured-data-models build that conflicts with
#                 kumo_tabular. Use `pip install "tabarena[seldon]"` in its own env.
tabarena[tabicl,ebm,search_spaces,realmlp,tabdpt,tabm,perpetualboosting,chimeraboost,nori,tabldm,kumo_tabular,lightpfn,prismboost,ftfm,tababax,inpriora,tabpack] @ git+https://github.com/autogluon/tabarena.git@39c3b4a8dcd18633551f9b1ff0585948250d8435#subdirectory=packages/tabarena
